# NotifyService

Сервис асинхронной отправки уведомлений пользователям.

## О проекте

**NotifyService** — это бэкенд-сервис, который позволяет отправлять уведомления пользователям через разные каналы (**Email**, **Telegram** и **SMS**) в асинхронном режиме.

Когда вы отправляете запрос на уведомление, сервис:
- Сохраняет информацию в базу данных
- Помещает задачу в очередь RabbitMQ
- Воркер в фоне забирает задачу и выполняет отправку

Благодаря асинхронной архитектуре API быстро возвращает ответ `202 Accepted`, не заставляя пользователя ждать завершения отправки.

## Основные возможности

- Асинхронная отправка уведомлений
- Поддержка каналов: **Email**, **Telegram** и **SMS**
## Основной API

### Отправка уведомления

**`POST /notify`**

**Пример запроса:**

```json
{
  "user_id": 42,
  "channel": "telegram",
  "message": "Привет я NotifyService bot, как дела?"
`}
```

**Поддерживаемые каналы (`channel`):**
- `email`
- `telegram`
- `sms`
